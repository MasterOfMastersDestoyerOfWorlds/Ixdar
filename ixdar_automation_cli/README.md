# Ixdar Automation CLI

`ixdar-cli` drives the running Ixdar app over its automation HTTP server (`http://127.0.0.1:47832`). Server-backed subcommands are generated from the Java routes manifest (`automation_routes.json`, regenerated by every Maven build from each route's `describe()`), so the CLI and the server never drift. Client-side commands come from the `@cli_command` registry.

## Install the global alias

```sh
bash tools/install-cli.sh      # or: uv run ixdar-cli install-alias
```

Creates `~/.local/bin/ixdar-cli` wrapping `uv run --project <repo> ixdar-cli`. Ensure `~/.local/bin` is on your `PATH`.

## Regenerating this file

```sh
uv run ixdar-cli gen-docs          # rewrite the CLAUDE.md region + this README
uv run ixdar-cli gen-docs --check  # CI/pre-commit drift gate
```

## Server-backed commands

### `click`

[↑ Contents](#contents) · [link to code](../ixdar-app/src/main/java/ixdar/platform/automation/endpoints/input/InjectClick.java)

Move the cursor to a point then issue a press/release click on the active mouse handler.

- **Route:** `POST /input/click`
- **Flags:**
  - `--x` (float, default `0`) — Target X coordinate., e.g. `0.5`
  - `--y` (float, default `0`) — Target Y coordinate., e.g. `0.25`
  - `--normalized` (bool, default `false`) — Treat X/Y as fractions of window size rather than pixels., e.g. `true`
  - `--button` (int, default `0`) — GLFW mouse button code., e.g. `1`
- **Response:** `{ok, event:{xPx, yPx, xNorm, yNorm, button}}`
- **Direct call:** `curl -s -XPOST http://127.0.0.1:47832/input/click -d '{"x": 0.5, "y": 0.25, "normalized": true, "button": 1}'`

### `mesh-compare`

[↑ Contents](#contents) · [link to code](../ixdar-app/src/main/java/ixdar/platform/automation/endpoints/mesh/Compare.java)

Compare the active viewer mesh against a reference OBJ using Hausdorff and Chamfer metrics.

- **Route:** `POST /mesh/compare`
- **Flags:**
  - `--reference` (string, required) — Path to the reference OBJ mesh to compare against., e.g. `~/Blends/Hand/Hand.obj`

- **Response:** `{ok, current_vertices, reference_vertices, hausdorff_distance, chamfer_distance, similarity_score, distance_type, scale, normalized}`
- **Direct call:** `curl -s -XPOST http://127.0.0.1:47832/mesh/compare -d '{"reference": "~/Blends/Hand/Hand.obj", "distance_type": "chamfer", "scale": 2.0, "normalize": true}'`
