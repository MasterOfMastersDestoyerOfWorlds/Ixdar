# AI Learnings

Store concise, reusable engineering learnings here.

## Structure

- `patterns/` for reusable successful approaches
- `failures/` for pitfalls and regressions
- `playbooks/` for repeatable procedural guidance
- `templates/` for standard write-up format

## Entry Rule

Write a learning when:

- A bug took significant effort to isolate
- A new pattern was introduced and validated
- A workflow/tooling improvement reduced repeated friction
